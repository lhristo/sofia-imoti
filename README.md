# София Имоти — статистика и сценарии

[Отворете сайта](https://lhristo.github.io/sofia-imoti/)

Сайт на български за исторически офертни цени на апартаменти в София. Включва сравнение на 144 квартала и местности, история за 2011–2026 г. и условни бъдещи сценарии. Не съдържа индивидуални обяви.

## Стартиране

Node.js 22 или по-нов. Няма външни зависимости.

```sh
npm run dev
npm run build
npm run validate
```

Локален адрес: http://localhost:4321.

## GitHub Pages

```sh
npm run build:pages
```

Качете обновената папка `docs/` в `main`. GitHub Actions публикува статичната версия автоматично.

## Методология

Източник: https://www.imot.bg/sredni-ceni . Историческите данни са извлечени на 18.10.2026 г. Използвана е най-близката налична справка до 15 октомври за всяка година от 2011 до 2026 г. Стойностите са моментни медианни офертни цени в евро на м², а не годишни средни или цени по сделки. Няма корекция за инфлацията. Липсващите стойности не се интерполират. Датите и източниците са в таблицата на сайта.

Бъдещите сценарии използват сложен растеж от базата за октомври 2026 г. Началният темп е CAGR за 2021–2026 г., изчислен с точните дати. Другите два сценария са с ±5 процентни пункта спрямо базовия темп. Потребителят може да промени темпа и хоризонта (3, 5 или 10 години). Това е илюстративна екстраполация, без вероятности, доверителни интервали и гаранция за бъдещите цени. Моделът не отчита лихви, доходи, предлагане, демография или бъдещи събития.
