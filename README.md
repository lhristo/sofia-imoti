# София Имоти

Сайт на български за имоти за продажба в София: обяви по квартал, филтри по бюджет и вид апартамент, запазени имоти и 15-годишна история на цените.

## Стартиране

Необходим е Node.js 22 или по-нов. Няма външни зависимости.

```sh
npm run dev
```

Отворете http://localhost:4321.

```sh
npm run build
npm run validate
```

## Структура

- `worker/index.js`: сървър, интерфейс и архивни данни.
- `scripts/preview.mjs`: локален сървър.
- `scripts/build.sh`: пакетиране за Sites.
- `.openai/hosting.json`: настройките на проекта в Sites.

## Данни и методология

Източник: https://www.imot.bg/sredni-ceni

Обявите са подбор от страницата на съответния квартал в Imot.bg и се кешират до 10 минути. Това не е пълният набор от имоти на пазара. При недостъпен източник за обявите се показва грешка, а за цените по квартали се използва датирана резервна справка.

Историческите данни са извлечени на 18.10.2026 г. Използвана е най-близката налична справка до 15 октомври за всяка година от 2011 до 2026 г. Стойностите са моментни медианни офертни цени, а не годишни средни или цени по сделки. Не са коригирани за инфлацията. Липсващите стойности не се интерполират. Таблицата в сайта съдържа точните дати и връзки към източниците.

## Отваряне на сайта

[Отворете София Имоти](https://lhristo.github.io/sofia-imoti/)

Версията в GitHub Pages е статична. Обявите са извлечени при подготовката на статичната версия, а датата е посочена на страницата. За обновяване изпълнете `npm run build:pages` и качете обновената папка `docs/`. При всяко качване в `main` GitHub Actions публикува тази папка. Локалната версия продължава да поддържа зареждане на обяви при отваряне на квартала.

```sh
npm run build:pages
```
